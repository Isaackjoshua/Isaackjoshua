### 📌 Featured projects

#### 🎗️ [Mwana AI — on-device breast cancer screening](https://github.com/Isaackjoshua/breast_cancer_ai)
`PyTorch` · `ResNet/MobileNet` · `ONNX Runtime` · `Flutter`

An offline-capable mobile application for AI-assisted breast ultrasound analysis. It classifies lesions into BI-RADS categories, segments the region of interest, and generates a structured clinical report — entirely on-device, with no cloud dependency after first setup. Android and [iOS](https://github.com/Isaackjoshua/mwana-ai-ios) versions.

➡️ **[View repository](https://github.com/Isaackjoshua/breast_cancer_ai)**

#### 🩺 [Triage — AI machine-diagnostics agent](https://github.com/Isaackjoshua/Triage)
`Python` · `Claude API` · `Agentic systems`

A transport-agnostic diagnostics agent: point it at a machine and it investigates system health through structured, tiered diagnostics — with a strict architectural boundary between *diagnosing* a problem and *changing* anything.

➡️ **[View repository](https://github.com/Isaackjoshua/Triage)**

#### 👁️ [Retinopathy — fine-tuning a retinal foundation model](https://github.com/Isaackjoshua/Retinopathy)
`PyTorch` · `RETFound` · `Transfer Learning`

Fine-tuned RETFound, a vision foundation model for retinal imaging, for diabetic retinopathy grading on a fundus-image cohort. Real medical-imaging ML: patient-level data handling, careful evaluation, and export toward deployable formats.

➡️ **[View repository](https://github.com/Isaackjoshua/Retinopathy)**

#### 📚 [Lyceum — desktop tutoring powered by Claude](https://github.com/Isaackjoshua/Lyceum)
`TypeScript` · `Claude API` · `Cross-platform desktop`

A cross-platform desktop app where anyone can be taught by Claude — turn any topic into a structured course and learn it interactively. Built as a real desktop product with its own learning flow, not a thin chat wrapper.

➡️ **[View repository](https://github.com/Isaackjoshua/Lyceum)**

#### 🏥 [DICOM-to-Video Extractor — medical imaging tool](https://github.com/Isaackjoshua/DICOM)
`Python` · `PyQt6` · `pydicom` · `FFmpeg`

Desktop application that loads DICOM studies, handles multi-frame and multi-series files, and exports them to MP4 with correct windowing for clinical review. Designed with proper handling of DICOM metadata and medical-imaging conventions.

➡️ **[View repository](https://github.com/Isaackjoshua/DICOM)**
